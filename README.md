# Руками не трогать!

Браузерная 2D-аркада. Игрок — продавец лекарственных трав за прилавком: покупатели
тянут руки к пучкам, вор хватает товар и убегает. Мультяшная рисовка на `<canvas>`,
озвучка — живые голоса участников.

**Играть:** https://sgmuwa.github.io/friends-games-pavel-rukami-ne-trogat/

Работает в браузере на десктопе и телефоне, ничего устанавливать не нужно.
Файл `ruki-ne-trogat.html` самодостаточен: можно скачать, переслать в мессенджере
и открыть двойным кликом — без интернета и без сервера.

## Предупреждение о содержании

Игра содержит **стилизованное мультяшное насилие**: удар мачете по руке, брошенный
в спину нож, красные частицы «крови» из плоских фигур. Ни фотореализма, ни реальных
людей, ни кадров реального насилия в игре нет. Сюжет комедийный, действие условное.

## Управление

- **Мышь / палец**: клик по руке у прилавка — мачете; клик по спине убегающего вора — нож.
- Оружие выбирается автоматически по цели, отдельной кнопки нет.
- Пауза и «Лавка» — кнопка на экране, на десктопе ещё клавиша `P`.
- Звук выключается иконкой в углу, реплики текстом включаются в «Лавке».

## Как устроено

| Что | Где |
|-----|-----|
| Исходник игры (HTML + CSS + JS в одном файле) | `src/game.html` |
| Исходные записи голосов | `audio-video/**/*.mkv` |
| Сборка звука: mkv → mp3, нормализация EBU R128 | `build/make-audio.sh` |
| Сборка игры: вшивает mp3 в HTML как base64 | `build/assemble.py` |
| Готовая игра — единственный файл поставки | `ruki-ne-trogat.html` |
| Полный дизайн-документ и журнал решений | `DESIGN.md` |

```bash
bash build/make-audio.sh      # нужен только когда меняются звуки (нужен ffmpeg)
python3 build/assemble.py     # после любой правки src/game.html
```

`ruki-ne-trogat.html` — **артефакт сборки**, руками его не правят: внутри 450 КБ base64.

## Публикация

Сайт публикуется workflow-ом `.github/workflows/pages.yml`: он копирует
`ruki-ne-trogat.html` в `site/index.html` и деплоит каталог `site/`. Исходники
(`src/`, `build/`, `audio-video/`, `DESIGN.md`) остаются в репозитории, но на сайт
не выкладываются.

Один раз в настройках репозитория: **Settings → Pages → Build and deployment →
Source: GitHub Actions**. Дальше каждый push с изменением `ruki-ne-trogat.html`
обновляет сайт сам.

Размеры с большим запасом укладываются в лимиты Pages (репозиторий ~4 МБ при
рекомендованном пределе 1 ГБ, сайт 1 МБ при пределе 1 ГБ).
